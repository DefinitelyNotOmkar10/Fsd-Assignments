## Running the Projects Locally

### Modules 1, 2, and 3 (Vanilla JS & Modern CSS)
No build steps or installations required.
1. Navigate into any folder (`1-calculator`, `2-todo-list`, or `3-form-validation`).
2. Open `index.html` directly in your favorite browser (Chrome, Edge, Safari, Firefox), or open the root `index.html` to browse all three from a unified hub.

---

### React Component Suite (`react-app`)
Powered by Vite and React 18.

1. Ensure **Node.js** (v18 or higher) is installed on your computer.
2. In your terminal or command prompt, change directory to the React app:
   ```bash
   cd react-app
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the local URL (typically `http://localhost:5173/`) to preview the interactive workspace.
